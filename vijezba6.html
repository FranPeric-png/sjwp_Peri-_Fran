Web Programiranje

HTML

HTML (HyperText Markup Language) je standardni jezik za izradu web stranica.

Osnovni elementi

HTML dokument se sastoji od elemenata koji se označavaju pomoću oznaka (tagova).

Tekst

Tekst se može oblikovati pomoću različitih oznaka, kao što su bold, italic, underline i druge.

Odlomci

Svaki odlomak se prikazuje u novom retku.

Prijelom reda

Za prijelom reda se koristi oznaka
